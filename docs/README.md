# Documentation Index

This documentation explains the public showcase version of the instrumentation and calibration workbench.

## Reading Order

1. `../README.md` - portfolio-facing overview.
2. `architecture/dataflow.md` - DAQ, TDK, snapshot, and CSV data flow.
3. `calibration/methodology.md` - synthetic calibration artifact workflow.
4. `workflows/runbooks.md` - commands for calibration, GUIs, dashboard, and code_xray.
5. `reproducibility.md` - public-release boundary, dependency notes, and data handling.

## Canonical Versus Supporting Material

The canonical technical docs are in `docs/`. The retained folders `test_logging/`, `tdklambda/data/`, `code_xray/`, and `SCD_3D_AI_Lab/` are supporting evidence and examples. The live snapshot file `tdk_snapshot.json` is retained as an approved runtime-state sample, not as a complete experiment record.
